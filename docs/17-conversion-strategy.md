# 17 — Conversion Strategy

## Primary Conversion Goal

**Contact form submission** — a visitor fills out the "Start a Project" form.

## Secondary Conversion Goals

1. Portfolio view (engagement signal)
2. Service page view (intent signal)
3. LinkedIn profile click (trust/networking)

---

## CTA Strategy

### Primary CTA
**"Start a Project"** — links to `/contact`

### Secondary CTA
**"View Our Work"** — links to `/work`

### CTA Placement Map

| Location | CTA | Type |
|----------|-----|------|
| Navbar (persistent) | Start a Project | Primary button |
| Hero section | Start a Project + View Our Work | Primary + Secondary |
| After services section | (Implicit via service cards) | Learn More links |
| After portfolio section | View All Work | Secondary link |
| After process section | Start a Project | Primary button |
| After Why NAVNA | (Implicit — near founders) | — |
| Founders section | LinkedIn links | Trust-building |
| Final CTA section | Start a Project | Primary button (large) |
| Each service page (bottom) | Start a Project | Primary button |
| Each project page (bottom) | Start a Project | Primary button |
| About page (bottom) | Start a Project | Primary button |
| Contact page | Send Message | Form submit |

### CTA Rules
- Maximum ONE primary CTA visible at a time (excluding navbar)
- Never stack 5 competing CTAs in a single viewport
- CTAs should feel natural, not aggressive
- Every page should have a clear path to contact

## Trust Signals

### What Builds Trust (Available)
| Signal | Implementation |
|--------|---------------|
| Real founders | Names, photos/initials, LinkedIn links |
| Professional design | The website itself is the #1 trust signal |
| Clear process | Transparent "How We Work" section |
| Honest content | No fake stats, no fake testimonials |
| Technical competence | Demonstrable through the website's quality |
| Direct communication | Contact form is simple and accessible |

### What's NOT Available (Don't Fake)
| Signal | Status |
|--------|--------|
| Client testimonials | ❌ None yet — omit |
| Star ratings | ❌ None — omit |
| Case study metrics | ❌ No real data — use qualitative descriptions |
| Awards/certifications | ❌ None — omit |
| Client logos | ❌ None — omit |

## Form Design for Conversion

### Reduce Friction
- Only required fields: Name, Email, Message
- Optional fields: Company, Project Type, Budget, Timeline
- No CAPTCHA (use honeypot instead)
- Clear validation messages
- Submit button says "Send Message" (not "Submit")

### Form States
| State | Design |
|-------|--------|
| Default | Clean, inviting, clear labels |
| Active (filling) | Inline validation, helpful feedback |
| Loading | Subtle loading indicator on button |
| Success | Clear confirmation message, "We'll be in touch" |
| Error | Clear error message with retry option |
